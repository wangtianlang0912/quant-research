# 存量豁免基线
#
# 格式：  path:line:CODE  理由
#         path:0:CODE     理由            （0 = 豁免整个文件的该规则）
#
# ★ 每条豁免都必须写理由。没有理由的豁免就是"我不知道为什么报错，先让它过"，
#   这类豁免积累到一定数量，门禁就形同虚设。
#
# ★ 每季度 review 一次（见 docs/operations.md 的检查清单）：
#   能修掉的就修掉，修不掉的重写理由。基线只减不增是硬目标。
#
# 常见豁免写法（行内，优先于本文件）：
#   value = 100  # noqa: ARCH002 -- 这里是 MinimalBar 构造的默认手数，非真实下单
#
