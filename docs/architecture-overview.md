# quant-research 架构总览

## 架构目标

本项目采用模块化单体架构，优先支持 A 股量化研究、回测验证与纸盘交易的最小闭环。
当前目标不是构建生产级高可用交易系统，而是建立稳定、可演进、可测试的研究与执行骨架。

## 分层结构

### 1. app
负责系统入口、命令行启动和依赖装配。

### 2. domain
定义核心领域模型、统一枚举、异常、运行上下文和抽象端口接口。

### 3. orchestrators
负责把数据读取、策略执行、风控审批、回测执行等流程串起来。

### 4. engines
负责提供回测引擎、指标引擎和风控实现等核心能力。

### 5. adapters
负责对接本地数据、第三方数据源和后续外部执行系统。

### 6. strategies
负责正式纳管策略实现，当前已接入趋势策略原型。

## 当前已实现能力

- 本地 CSV 历史数据读取
- 趋势策略原型
- 最小回测运行器
- 基础风控
- 基础绩效指标
- CLI 回测入口
- 最小核心测试

## 当前演进方向

1. 继续增强风险控制规则。
2. 将回测指标沉淀为更明确的报告输出。
3. 逐步补齐 paper 模式运行闭环。
4. 后续统一本地 CSV 适配器命名。
