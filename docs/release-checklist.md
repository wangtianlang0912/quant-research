## 使用说明

每次策略晋级时，必须完整填写对应阶段的检查清单。  
所有 `[ ]` 项目必须全部勾选（`[x]`）后，方可进入下一阶段。  
签字人必须是真实负责人，不得代签。

## 附：实盘运行后持续监控清单

实盘开始后，每周/每月执行以下检查：

### 每日检查

- [ ] 账户净值与系统计算一致
- [ ] 风控日志无异常触发
- [ ] 未成交订单处理完毕

### 每周检查

- [ ] 实盘绩效与纸盘/回测对比报告生成
- [ ] 换手率、交易成本在预期范围内
- [ ] 风控规则触发频率正常

### 每月检查

- [ ] 月度绩效归因分析完成
- [ ] 风控参数是否需要调整（由风控负责人决策）
- [ ] 策略是否出现失效迹象（如持续跑输基准 + 盈亏比恶化）

### 触发策略重评估的条件

- 实盘运行 3 个月，年化超额收益 < 0%
- 最大回撤超过回测预期 1.5 倍
- 连续 2 个月策略绩效显著低于预期
- 市场结构发生重大变化（监管政策、交易机制等）
